# Roast Contours

Original 2560×1440 wallpaper made for Krema: faint topographic contour lines
on a warm dark gradient (palette A). Used as the desktop wallpaper in the
site's Plasma vs Krema section (`website/media/roots-wall*.webp`, bottom band).

`gen.py` regenerates the PNG (needs numpy and Pillow).
