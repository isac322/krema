# Krema Dock

> A high-performance, modular, and mathematically rigorous dock for KDE Plasma 6 and Hyprland.

Krema is the spiritual successor to Latte Dock, built from the ground up for the modern Wayland era. It prioritizes stability, visual smoothness, and a recursive "Tree of Islands" architecture.

## 🚀 Key Features

- **3-Tier Modularity:** A recursive hierarchy of Panels, Islands, and Items.
- **Dual Personality:** Seamlessly switch between **Icon-Only** (with Parabolic Zoom) and **Icon-Label** (stable taskbar) modes.
- **Tablet-Class Folders:** Recursive folders with inline or pop-up expansion.
- **Omnidirectional Axis:** Identical behavior on Top, Bottom, Left, or Right screen edges.
- **Multi-Monitor Mastery:** Independent instances per screen with Activity and Virtual Desktop filtering.
- **Kinetic Physics:** Zero-latency, C++23 powered parabolic zoom engine.

## 🛠 Tech Stack

- **Language:** C++23
- **Framework:** Qt 6.8+ (Qt Quick / QRhi)
- **Desktop:** KDE Plasma 6 (Wayland) / Hyprland
- **Build System:** CMake + Ninja
