The zooming dock for KDE Plasma 6

Krema is the spiritual successor to Latte Dock, built for KDE Plasma 6 and native to Wayland. It pairs parabolic zoom with live PipeWire window previews.

Krema is the spiritual successor to Latte Dock, written from scratch for Plasma 6 with Qt 6, KDE Frameworks 6 and the Wayland layer shell. Both sides use Breeze Dark and KDE’s Breeze icons (LGPL-3.0). Firefox and its logo are trademarks of the Mozilla Foundation.

Install in two steps

  1. 1Add the package

    yay -S krema

    Arch Linux and Manjaro, from the AUR. paru -S krema works too.

    sudo dnf copr enable isac322/krema
sudo dnf install krema

    Fedora 42, 43, 44 and Rawhide, from COPR.

    sudo add-apt-repository ppa:isac322/krema
sudo apt update
sudo apt install krema

    Ubuntu 25.10 and 26.04, from the Launchpad PPA. On 25.04, use the OBS repository.

    sudo zypper addrepo https://download.opensuse.org/repositories/home:isac322/openSUSE_Tumbleweed/home:isac322.repo
sudo zypper refresh
sudo zypper install krema

    This is for Tumbleweed. On Slowroll or Leap 16.0, swap openSUSE_Tumbleweed for openSUSE_Slowroll or openSUSE_Leap_16.0.

    echo 'deb http://download.opensuse.org/repositories/home:/isac322/Debian_13/ /' | sudo tee /etc/apt/sources.list.d/krema.list
curl -fsSL https://download.opensuse.org/repositories/home:isac322/Debian_13/Release.key | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/home_isac322.gpg > /dev/null
sudo apt update
sudo apt install krema

    Debian 13 (Trixie), from the Open Build Service.

    git clone https://github.com/isac322/krema
cd krema
just configure
just build
just run

    Needs C++23, Qt 6.8 or newer, KDE Frameworks 6 and CMake 3.22 or newer. The README lists every dependency.

  2. 2Open Krema

    Start Krema from the app launcher. From then on it starts with your session.

    To change how it looks, right-click the dock and choose Settings.

    Packages need Plasma 6.0 or newer and are built for x86_64 and aarch64 (Slowroll: x86_64 only).

If you use Krema, a star on GitHub helps other Plasma users find it.
