krema

The zooming dock for KDE Plasma 6

Krema has parabolic zoom and live PipeWire window previews, runs natively on Wayland, and is the spiritual successor to Latte Dock.

roots · Krema

Latte Dock stopped at Plasma 5. Krema starts at 6.

Krema is its spiritual successor, written from scratch for Plasma 6 in C++23 with Qt 6, KDE Frameworks 6 and the Wayland Layer Shell. It has no X11 code.

The stock Plasma panel still has no parabolic zoom. Krema’s core features work today, and the rest is on the roadmap.

See it in action

Everything a dock should do, done the Plasma way

Core dock

Pin favorites, see what runs, jump to it.

Parabolic zoom
Icons grow under the pointer and settle as it leaves. You set how far they grow.
Even icon sizes
Krema detects padding built into icon themes and rescales, so icons line up.
Pinning and running dots
Pinned apps stay in place, and a dot marks each open one.
Scroll to cycle
Scroll over an app to step through its windows.
Backgrounds
Panel-matched, transparent, tinted or frosted acrylic. Adaptive opacity turns the dock solid when a window touches it.
Visibility
Always visible, auto-hide, or dodge windows.

Previews

See the window before you switch to it.

Live PipeWire thumbnails
Hover an app to watch its windows update live, captured on the GPU.
Grouped windows
All of an app’s windows sit side by side in one popup.
Click to switch
Click a thumbnail to raise that window.
Close from the preview
Close a window from its thumbnail.

Notifications & attention

A calm dock that still tells you when something needs you.

Badges
Unread counts from the SmartLauncher (Unity) D-Bus API, shown as a number, a dot, or not at all.
6 attention animations
Bounce, wiggle, pulse, glow, dot color or blink. They stop after a delay you choose.
Task progress
Long jobs, like a Dolphin file copy, draw a progress bar on the icon.
Do Not Disturb
When Plasma’s Do Not Disturb is on, attention animations stay quiet.

Multi-monitor

One dock, many screens, each set up its own way.

Where the dock lives
The primary screen, every screen, or the one with the active window.
Follow triggers
Mouse position, keyboard focus, or both.
Per-screen overrides
Each monitor can have its own icon size, edge and visibility mode.
Virtual desktops
Show tasks from every desktop, dim the others, or list only the current one.

Plasma integration & accessibility

Built with Kirigami, KConfig, KColorScheme and KGlobalAccel.

Native look
Plasma theme colors, your color scheme, Breeze context menus and a Kirigami settings window.
Drag and drop
Reorder icons, drop files onto apps, or drag in a .desktop file to add a launcher.
Keyboard first
Every item works without a mouse, and AT-SPI exposes the dock to screen readers.
Starts with your session
Launches at login and keeps one instance running.

Global shortcuts

KGlobalAccel holds them, so they work from any window.

Global shortcuts
Meta + `Show or hide the dock
Meta + 1–9Activate the app in that slot
Meta + Shift + 1–9Open a new instance of it
Meta + F5Move keyboard focus into the dock

Install Krema

Pick your distribution and paste one command, then start Krema from the app launcher. Packages need Plasma 6.0 or newer and are built for x86_64 and aarch64 (Slowroll: x86_64 only).

  1. Arch Linux & Manjaro

    From the AUR, with any helper

    yay -S krema

  2. Fedora

    42, 43, 44 and Rawhide via COPR

    sudo dnf copr enable isac322/krema && sudo dnf install krema

  3. Ubuntu

    25.10 and 26.04 via the Launchpad PPA

    sudo add-apt-repository ppa:isac322/krema && sudo apt install krema

  4. openSUSE & Debian

    Tumbleweed, Slowroll, Leap 16.0, Debian 13 and Ubuntu 25.04 on the Open Build Service

    Add the repository that matches your release, then install the krema package.

    Open the OBS package

  5. From source

    C++23, Qt 6.8+, KDE Frameworks 6 and CMake 3.22+

    Dependencies and build steps live in the repository README.

    Build instructions on GitHub
