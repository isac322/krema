krema

The zooming dock for KDE Plasma 6, native to Wayland.

Parabolic zoom, live window previews and the Plasma theme you already picked. Krema is written in C++ against KDE’s own frameworks, runs natively on Wayland, and is the spiritual successor to Latte Dock.

roots — Krema

Latte Dock stopped at Plasma 5. Krema starts at 6.

If your desktop lost its dock during the Plasma 6 upgrade, Krema is here to fill the gap. It is a spiritual successor to Latte Dock, written from scratch for Qt 6, KDE Frameworks 6 and the Wayland Layer Shell protocol, with no X11 code to carry along.

Rendering runs on the GPU through Qt’s QRhi, previews stream through PipeWire, and nothing is allocated until the dock actually needs it.

Everything a dock should do, done the Plasma way

Core dock

The behavior your hands expect, tuned from the settings window rather than a config file.

Parabolic zoom
Icons swell smoothly under the pointer and settle back as it leaves, with adjustable magnification.
Even icon sizes
Krema detects built-in padding in icon themes and rescales so every app lines up.
Pinning and running dots
Keep favorites in place; a dot under each icon marks what is open.
Scroll to cycle
Turn the wheel over an app to step through its windows.
Backgrounds
Inherit your panel style, go semi-transparent or fully clear, tint it, frost it with acrylic blur, follow your accent with Mica, or let adaptive opacity turn solid when a window touches the dock.
Three visibility modes
Always visible, auto-hide, or dodge windows.

Previews

See a window before you switch to it, without the dock getting in the way.

Live PipeWire thumbnails
Hover an app to watch its windows update in real time, captured on the GPU.
Grouped windows
Every window of an app appears side by side in one popup.
Click to switch
Pick a thumbnail to bring that exact window forward.
Close from the preview
Dismiss a window right from its thumbnail.

Notifications & attention

A calm dock that still tells you when something needs you.

Badges
Unread counts arrive over D-Bus and the SmartLauncher (Unity) API, shown as a number, a dot, or not at all.
6 attention animations
Bounce, wiggle, pulse, glow, dot color or blink, stopped automatically after a delay you choose.
Task progress
Long jobs, like a Dolphin file copy, draw a progress bar on their icon.
Respects Do Not Disturb
When Plasma’s DND is on, attention animations stay quiet.

Multi-monitor

One dock, many screens and desktops, each set up the way that screen is used.

Where the dock lives
On the primary screen, on every screen, or following the active window.
Follow triggers
Move by mouse position, by keyboard focus, or by both.
Per-screen overrides
Give each monitor its own icon size, edge and visibility mode.
Virtual desktops
Show tasks from every desktop, dim the others, or list only the current one.

Plasma integration & accessibility

Built with Kirigami, KConfig, KColorScheme and KGlobalAccel, so it behaves like part of the desktop.

Native look
Plasma theme colors, your color scheme, Breeze context menus and a Kirigami settings window.
Drag and drop
Reorder icons, drop files onto apps, or drag in a .desktop file to add a launcher.
Keyboard first
Every item is reachable without a mouse, and AT-SPI exposes the dock to screen readers.
Starts with your session
Launches on login and keeps a single instance running.

Global shortcuts

Held by KGlobalAccel, so they work wherever focus is.

Global shortcuts
Meta + `Show or hide the dock
Meta + 1–9Activate the app in that slot
Meta + Shift + 1–9Open a new instance of it
Meta + F5Move keyboard focus into the dock

On a real Plasma 6 desktop

Install Krema

Packages are built for x86_64 and aarch64 and need Plasma 6.0 or newer. Pick your distribution, paste one command, then start Krema from the app launcher.

  1. Arch Linux & Manjaro

    From the AUR, with any helper

    yay -S krema

  2. Fedora

    42, 43, 44 and Rawhide via COPR

    sudo dnf copr enable isac322/krema && sudo dnf install krema

  3. Ubuntu

    25.10 and 26.04 via the Launchpad PPA

    sudo add-apt-repository ppa:isac322/krema && sudo apt install krema

  4. openSUSE & Debian

    Tumbleweed, Slowroll, Leap 16.0, Debian 13 and Ubuntu 25.04 on the Open Build Service

    Add the repository that matches your release, then install the krema package.

    Open the OBS package

  5. From source

    C++23, Qt 6.8+, KDE Frameworks 6 and CMake 3.22+

    Dependencies and build steps live in the repository README.

    Build instructions on GitHub
